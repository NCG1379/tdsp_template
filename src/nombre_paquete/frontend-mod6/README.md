# ¿Cómo ejecutar el Frontend?

Hola, usted está ahora en la ruta para poder ejecutar el Front.


Siga estos pasos para ejecutarlo:

1. **Instala las dependencias**  
   Ejecutar el siguiente comando para instalar todas las dependencias necesarias:
   ```bash
   npm i
   ```

2. **Inicia el frontend**  
   Iniciar la aplicación con:
   ```bash
   npm start
   ```
   Al correr este comando, la terminal te indicará el puerto en el que está corriendo la aplicación (generalmente es el `3000`, pero esto se puede ajustar luego con Docker).

> **Nota:**  
> En esta versión (Julio 19), el frontend aún no realiza llamadas al backend; solo se hacen llamadas a APIs de ejemplo.
